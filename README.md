# 香港學校 IT Service Desk System

這是一個專為香港學校設計的 IT 服務台系統，用於管理校內的資訊科技支援請求。

## 系統特色

- 🎨 **現代化介面**：採用響應式設計，支援桌面和移動設備
- 📊 **實時統計**：顯示工單總數、待處理、處理中和已解決的統計數據
- 🔍 **智能篩選**：可按狀態、優先級、分類和關鍵字搜尋工單
- 📝 **快速提交**：簡化的工單提交表單，支援多種問題分類
- 🔄 **狀態管理**：完整的工單生命周期管理（待處理 → 處理中 → 已解決）

## 技術架構

### 後端 (Backend)
- **Node.js + Express**: RESTful API 伺服器
- **功能**:
  - 工單 CRUD 操作
  - 統計數據生成
  - 篩選和搜尋功能
  - 模擬數據庫（可擴展至真實數據庫）

### 前端 (Frontend)
- **純 HTML/CSS/JavaScript**: 無需額外框架
- **功能**:
  - 儀表板統計展示
  - 工單列表和詳情查看
  - 工單創建和更新
  - 實時篩選和搜尋

## 安裝與運行

### 1. 啟動後端伺服器

```bash
cd backend
npm install
npm start
```

後端伺服器將在 `http://localhost:3001` 運行

### 2. 開啟前端頁面

在瀏覽器中打開 `frontend/index.html` 文件，或使用任何靜態文件伺服器：

```bash
# 使用 Python 簡單伺服器
cd frontend
python3 -m http.server 8080
```

然後在瀏覽器訪問 `http://localhost:8080`

## API 端點

| 方法 | 端點 | 描述 |
|------|------|------|
| GET | `/api/tickets` | 獲取所有工單（支援篩選） |
| GET | `/api/tickets/:id` | 獲取單一工單詳情 |
| POST | `/api/tickets` | 創建新工單 |
| PUT | `/api/tickets/:id` | 更新工單 |
| DELETE | `/api/tickets/:id` | 刪除工單 |
| GET | `/api/stats` | 獲取統計數據 |
| GET | `/api/options` | 獲取選項列表（分類、優先級、狀態） |

## 工單分類

- 🖥️ **硬件問題**: 電腦、投影機、打印機等硬件故障
- 💻 **軟件問題**: 應用程序、系統軟件問題
- 🌐 **網絡問題**: 網路連接、WiFi 問題
- 🔐 **帳號權限**: 密碼重設、帳號權限管理
- 📧 **電郵系統**: 電郵相關問題
- 📦 **其他**: 其他 IT 相關問題

## 優先級別

- 🔴 **緊急**: 影響教學或重要業務，需即時處理
- 🟠 **高**: 重要問題，需盡快處理
- 🟡 **中**: 一般問題，正常處理流程
- 🟢 **低**: 輕微問題，可延後處理

## 使用場景

1. **老師提交問題**: 老師遇到 IT 問題時，填寫表單提交工單
2. **IT 人員處理**: IT 技術員查看工單列表，更新狀態並記錄解決方案
3. **管理員監控**: 透過統計數據了解 IT 支援情況和資源分配
